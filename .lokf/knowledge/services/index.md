# Services

* [linkml-scaffold.sh](linkml-scaffold.md) - The scaffold script that does Steps 1 to 3 of linkml-sidecar in one deterministic run: it verifies the template pin, stages the skill's files and copier's output, moves them into .linkml/ around what is already there, keeps the generators' settings in generators.yaml, adopts a schema the host holds with --adopt, names the schema in a KTL bundle's justfile, adds the root pointers, and exits 0, 2, 3, 4 or 5.
* [linkml-preflight.sh](linkml-preflight.md) - The read-only preflight both skills run first: one screen of ok, warn, missing and info lines about the host's shell, git, forge, uv, copier, just and network, where a LinkML schema project or schema file sits, how to run the tools on it and how many people have committed to it, a .lokf/ bundle and Pages, ending in a summary line of what is missing and which steps that disables.
* [linkml-sidecar workflow](linkml-sidecar-workflow.md) - The one GitHub Actions workflow the sidecar installs at .github/workflows/linkml-sidecar.yaml: lint and test in .linkml/ from the locked environment, build the docs site on the default branch, and publish it under the linkml/ subpath of gh-pages only while LINKML_DOCS_ENABLED is true.
* [Repository contract](repository-contract.md) - scripts/validate-repository.sh and the validate.yml workflow: the checks every pull request runs on this repository, covering skill shape, links, word budgets, the one template pin, shared action pins, prerequisites rows, the changelog, invisible characters, plus pytest, ShellCheck, actionlint, markdownlint, lychee, codespell and the install smoke test.
